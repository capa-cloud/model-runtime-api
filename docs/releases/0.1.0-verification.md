## Security and disclosure review

- Repository content contains no known credentials, private endpoints, customer payloads, production
  logs, private prices, routing weights, internal system names, private IPs, or local user paths.
- Provider configuration accepts environment-variable names and rejects inline credential fields.
- SDK URLs reject embedded credentials and fragments.
- Provider SSE and JSON responses have bounded frame/body sizes.
- fal lifecycle URLs must remain on the configured origin; returned artifacts are recorded but not
  fetched.
- Telemetry mapping is metadata-only and excludes prompt/output content.
- GitHub Secret Scanning, Push Protection, Dependabot security updates, and private vulnerability
  reporting are enabled.

## Explicit limits

- The reference server is unauthenticated and must remain on loopback or behind an authenticated
  gateway.
- The bundled EventStore is in-memory. Durable production stores and distributed flow control are
  deployment extensions.
- Provider adapters are contract-tested against public documentation and local fixtures, not
  certified against live provider accounts.
- Customer billing, wallets, discounts, tax, invoices, and tenant management are outside this
  project.
